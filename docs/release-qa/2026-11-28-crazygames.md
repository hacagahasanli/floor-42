## BLOCKERS

### B1. Uncaught `TypeError` on every match start and on every window resize
- **Evidence:** every run logs a page error: `TypeError: Cannot read properties of null (reading 'setAttribute') at fit (index.html:86:59)`, called from `assets/index-CmY8sjFV.js:4264:59314`. It fired in all 9 CrazyGames QA sizes, phone landscape and portrait, 1P, 2P and the throttled runs (`s2.json`, `s3.json`, `s6.json`, `s7.json`). In the live-resize run it fired once per resize, 7 times in 7 resizes (`s2.json` → `resize.errors`).
- **Cause:** `portal/index.html` (boot script) runs `window.addEventListener('resize', fit)` and never removes it. `App.tsx` removes `#boot` 200 ms after the first paint. After that, `document.getElementById('boot-bunting')` is null, so `fit()` throws. `ArenaGame.tsx:236` sends `window.dispatchEvent(new Event('resize'))` when a match mounts, so every match start throws. On CrazyGames, entering or leaving fullscreen and resizing the window throw as well.
- **Why it blocks:** /requirements/gameplay asks for "no errors or crashes". The 27 Nov builds had 0 console errors, so this is a regression in the update. CrazyGames QA sees uncaught errors in devtools and in their QA tool.
- **Repro:** serve the zip, open it, click PLAY, and check the console. Or resize the window at any point after the menu shows.
- **Fix (Claude Code, about 10 min, not in `src/`):** in `portal/index.html`, start `fit()` with `var b=document.getElementById('boot-bunting'); if(!b||!boot.isConnected) return;`, or call `removeEventListener('resize', fit)` when the boot screen is removed. Rebuild, then confirm `log.pageerrors` is empty in `s1-match.mjs` and `s2-sizes.mjs`.

## SHOULD-FIX (not reject reasons in the written requirements; ordered by risk)

1. **The key-hint strip collides with the AIM / SHAKE pills at 821x462 and 800x450.** These are CrazyGames' own QA sizes: desktop non-fullscreen and mobile. At 821x462 the "AIM: AUTO (T)" pill covers the "Pause" label of the ESC hint (`s2-821x462-fight.png`); 800x450 is the same (`s2-800x450-fight.png`). At 907x510 the two touch but do not overlap. The strip shows by default in the first matches. Owner: Claude Code (layout), and the Creative Director if the pills need to move. About 15 min. This is the item closest to a blocker: /requirements/gameplay asks for readable text at these sizes. Fix it today if B1 is being rebuilt anyway.
2. **HUD text measures 7.2-7.5 CSS px at 800x450 and 821x462** ("YOU", "BOT · EASY", the weapon, DASH and PUSH chips, "FIRST TO 5"). The menu at those sizes has 8-9 px chips and footers (`s2.json`). It reads, but it is small. Owner: Creative Director (minimum type size per stage scale).
3. **The 2P result screen can be skipped by mashing.** Both players pressing Shoot starts the rematch. With both shoot keys mashed through the final KO, the result went straight to the next match: `gameplayStop` at 99 358 ms, then `gameplayStart` at 101 723 ms (2.4 s, which is only the doors plus countdown), and the same again at 192 105 → 194 470 (`s6.json`). In 1P, Enter is locked for the first 0.6 s. 2P needs the same lock, and probably a longer one, so the awards are seen. Without mashing, the 2P result shows correctly and Shoot+Shoot rematches (`s7.json`, `s7-2p-result.png`). Owner: Claude Code, 15 min.
4. **The 2P "BOTH PRESS SHOOT TO FIGHT" key card still uses the old dark developer theme** (navy panels, Chakra Petch / Bungee fonts; `s5-2p-fight.png`, `src/components/twoPlayer/KeyCard.tsx`). HANDOFF says the developer theme was removed. It is the first thing every 2P match shows. Owner: Creative Director (spec), then Claude Code.
5. **OFL font licences are missing.** The zip ships `bungee-400` and four `chakra-petch-*` woff2 files (loaded by `portal/portal.css`), but `licenses/` holds only Baloo 2 and Titan One. The SIL OFL requires the licence to travel with redistributed fonts. Owner: Claude Code, 5 min. Add the two OFL texts, or drop the fonts once item 4 is done.
6. **Covers look cheaper than the CrazyGames front page.** The new covers meet the rules: 1920x1080, 800x1200 and 800x800, title only, no borders. But they are flat in-engine renders, the figures are small, and they are side-on with neutral faces. The top picks and new games in `_studio/refs/crazygames-top-covers-1.png` use close-up, high-contrast, expressive illustration (Final Drop, POW, Gap Run). Studio rule: if ours looks cheaper, that matters. It is a click-rate risk, not a reject reason, and the old covers are not an option (they say FLOOR 42). Ship these now and give the Creative Director an R- item for a punchier cover before the Basic Launch metrics window.
7. **1P gamepad play.** A pad drives the menus (d-pad and A start a match: `s3.json` pad steps). In a 1P match, Start does not pause and the pad does not move the fighter (`s3-pad-pause.png`, Start → no PAUSED). The store copy already claims gamepads for 2 players only, so nothing is mis-sold. Owner: Claude Code (backlog).
8. **Enter on the home screen does nothing until a button has focus.** The PLAY button carries an "ENTER" hint, but after a player clicks into the iframe, focus is on `BODY` and Enter does not start a match (`s5.json` `enterFromBody: false`). ArrowDown and then Enter works. Owner: Claude Code, 10 min (default focus on PLAY, or a global Enter on home).
9. **The sound button does not show the portal mute.** With `muteAudio: true`, the home Sound button reports `aria-pressed=false` (sound on), although `effectiveMute()` = player mute OR portal mute keeps audio off (`settings.ts:318`). Pressing it does not re-enable sound, which is correct per /sdk/game. Only the icon is wrong. Basic Launch does not require `muteAudio`. Owner: Claude Code.
10. **An AudioContext is created before any user gesture.** Chrome logs "The AudioContext was not allowed to start" twice on the phone and 6x-throttled profiles (`s2.json`, `s4-x6.json`). These are warnings, not errors, and sound resumes on the gesture path (`sfx.ts`). Owner: Claude Code (create the context on the first gesture only).
11. **One 400 ms frame in the first match.** S1 match 1 had 2 frames over 50 ms, max 400 ms. Match 2 had none (`s1-1280.json`). This looks like a first-use hitch (shader or texture on first sight of an effect); the source was not isolated. The menu's first 2 s at 4x and 6x CPU throttle: p95 100-150 ms. Owner: Claude Code (pre-warm on the VS doors).
12. **Carried from 27 Nov, unchanged:** Esc is the only keyboard pause, and Esc also leaves CrazyGames fullscreen (/requirements/quality guideline). Touch is detected with `pointer: coarse` / `ontouchstart` instead of SDK device info (`src/game/input.ts:13`, `src/game/render/quality.ts:58`). /requirements/technical "strongly recommends" the SDK. Keep the form set to desktop only.
13. **Old meta description.** The build still has "Pewfield is a 1v1 shootout. Pick a fighter, grab a gun, first to five KOs wins." The Creative Director replaced it in F-065 (`CREATIVE/brand/crazygames-store.md` section 6). Players on CrazyGames do not see it.
